# 十项目 H0/H1 完整对照修订

日期：2026-10-03。用户要求先完成十项目交接对照，再判断 H0 和 H1。本修订取代 10 月 2 日计划中只用 CSV、Net 决定共同交接方式的安排。

## 先后顺序

1. 暂停 code mode × Advisor 四组的后续派发。已经开始的一次 CSV 基线运行正常收尾，原始结果、成本和暂停记录保留，单列为工程试运行。
2. 撤回基于两项目作出的 H0 采用决定。八次已完成对照继续保留为开发数据，不删除，也不并入新的主比较。
3. 新跑十项目 × H0/H1 × 两次重复，共 40 次完整 setup。全部结束后，先比较完成情况，再比较成本与行为。
4. 共同交接方式有足够依据后，再恢复四组试运行。十项目四组两次的 80 次正式对照仍在后面，不提前派发。

本次重新跑 CSV、Net，是为了让全部主比较使用同一源码和镜像。前八次使用的是 code 候选接入前的版本。新一轮使用当前版本，两组均显式关闭 code mode。不能用“开关关闭，应该没有区别”代替版本控制。

## 固定任务与运行条件

项目仍为 Commons CSV、Commons Net、Commons DbUtils、Tomcat Jakarta EE Migration、Sling Commons MIME、Creadur Whisker、Commons DBCP、Gson、HttpComponents Core 和 FreeMarker。沿用已有固定提交、CI 任务、requirements、来源记录和规模标签，不因结果更换项目。

每项目两种方案各跑两次。第一轮相邻配对，五个项目 H0 先跑、五个项目 H1 先跑；第二轮反转项目顺序与组内次序。两次重复沿用原计划，用于观察基本波动，不声称具有充分统计功效。

- H0：任务事实、未完成要求、适用 receipt、完整阶段结论和可读引用。
- H1：H0 加与下一阶段未决问题有关的已读原文。
- 两组唯一配置差异为 `phase_context_policy`。完整交接 intro 都限 6,000 字符。
- Actor：gpt-5.4-mini，temperature=0，输出上限 10,000，不显式发送 reasoning_effort。
- Advisor、Actor 主动咨询入口、code mode 均关闭。其他未批准的 prompt、阶段复用和自动导出开关保持关闭。
- 本地同一镜像；新建冷容器；串行运行；4 CPU、8 GiB，无额外 swap；每次 7,200 秒、150 次 Actor 请求、150 次逻辑工具调用。
- 每 15 秒记录资源；磁盘保留线 32 GiB。大项目不并行。归档核验后只清理本次拥有的停止容器。

H0/H1 的 provider schema 必须都没有 Advisor 或 code 入口。检查实际配置、请求阶段绑定、receipt 阅读视图、完整工具输出与离线评分。每次正式命令继续传入冻结的 acceptance task、requirements 和 CI target。

## 比较与决定

首先逐项目列出两次重复的 whole-task、build、test、要求通过数、缺证据项、模块、主/测试 class、JAR 和 tests ran。成功仍由规定要求及独立物理证据确定。

然后报告全部尝试的 input/output、cached/uncached、总 token、无人反馈墙钟、峰值 RAM 和磁盘。每项目先求配对差，再作项目等权汇总；同时展示各项目差值，不能让 token 较大的项目决定整体结论。失败的低 token 不解释为效率优势。

行为分析单列首次原文交接之前和之后的成本、实际原文交付、重新读取、错误修复与重复执行。H1 没有实际交付原文的运行仍保留在原组，不挑选“使用了原文”的成功案例作为主分析。

只有全部 40 次有结局或明确的未开始原因，才进行采用讨论。采集缺失、版本漂移、资源越界或错误成功判定会停止后续派发，普通项目失败仍保留并继续预定顺序。重跑要另记版本和原因，不能覆盖原尝试。

十项目完成后仍可能没有明确赢家。结果应说明差值及不确定性，不能为了选方案把噪声写成设计效果，也不能以两次重复证明普遍可靠性。

## 研究范围与预算记录

全部十项目现在参与交接方式的选择。原来的八个非开发项目不能再称为本轮交接决策的留出验证集。后续四组在同一十项目上的结果属于选定 benchmark 内的机制比较；跨项目泛化需要另一个未参与选择的项目集。

新的主比较为 40 次。之前八次本地开发对照、这次已开始的一次四组试运行，以及远端运行分别保留并计入总体成本。它们不补足这 40 次的分母。

当前不恢复后续四组。等本轮完成并复核，再更新四组协议、顺序和实际预算。既有 OpenAI API 授权继续适用。
