# Agent 自主执行与独立复跑的评测边界修复

用户于 2026-09-26 授权修复。保留 SAG 的 phase 状态机、阶段完成声明、物理验证和模型工具说明。本轮先修正测量，不把 Advisor/phase 的开销分析当作取消这些机制的因果证据。

## 要修复的问题

旧 portable controller 在 Agent 退出后执行冻结的 CI 命令，并把这次执行作为共同评分来源。部分 Agent 只完成环境准备或留下后台任务，仍可由控制器得到 complete。该结果可以描述环境可执行性，不能证明 Agent 自主完成 build/test。三组使用同一重跑程序，也不能消除实际工作范围不同的偏差。

## 边界与不变量

1. Agent 指模型及其自身 harness。SAG 状态机内部派发、等待、验证属于 SAG 的执行，计入其预算；三组之外的公共评测器不能补做任务。
2. 主结果仅采纳 Agent 执行窗口内、来源与任务绑定的证据。模型自述、工具返回“成功”、产物存在或外部复跑成功，都不能单独证明任务 complete。
3. 公共评分器只读封存证据。独立复跑使用单独的证据来源和结果，不得填补主结果缺失的命令、产物或测试，也不能改变已封存主结果。
4. 尚在执行的要求命令不得被成功关闭；必须有真实终态。等待与证据采集开销计入 Agent 时间；外部复跑时间单列。
5. 未执行只有在采集覆盖充分时才能判定；缺失、未覆盖、冲突保持 unavailable。失败尝试与所有用量保留，不拼接不同尝试的最佳要求。
6. task/requirements/CI 定义继续使用现有严格检查；增加执行来源协议，不修改 CI 要求以迁就任何 harness。
7. 既有 60 次运行及其校验和、评分和报告保持原样。重评产出新版本，明确原始分数的语义及历史证据限制。

## 接入要求

在命令实际执行前后绑定原始命令、cwd、运行时、退出/超时状态、完整日志、工作树状态、模块与产物、测试报告及来源。Agent 自己可以探索、修复和重试；采集器不应替它挑选命令或修改执行参数。受支持路径必须有实测覆盖，未覆盖路径不能默认成功。

研究结果区分：自主任务完成率、build/test 要求完成、CI 对齐、独立复跑结果。Token 以服务端 usage 为准，Actor/Advisor 分列；时间与产物归属使用同一执行边界。
